Last dashboard template ab site ke navy palette par hai. Screenshot me mark kiye teen jagah — Media Library button, Doctor Alerts icon, aur telehealth video icon — sab theek ho gaye.

2. Desktop

  • Upload Photo — navy #1A528E, hover #00346C.
  • Media Library — soft slate, pink hover khatam.
  • Remove — red outline #B91C1C, hover par solid red.
  • Sidebar tiles — active tile solid navy; idle tiles white + navy icons; hover par halka blue tint aur navy border.
  • Form controls — border #E2E8F0, focus par navy border + soft navy ring (Bootstrap ka default blue ring nahi).
  • Checkboxes (notification preferences) — navy fill, navy focus ring.
  • Success ticks/pills semantic green hi rahe — wo status hai, brand colour nahi.
