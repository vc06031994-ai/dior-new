Consultation Card Logic + Profile Banner Theme

Do cheezein: card ke buttons ab appointment data ke hisaab se decide hote hain, aur amber profile banner navy theme par aa gaya.

1. Bug: button hamesha dikh raha tha

Card "No upcoming consultation" keh raha tha, phir bhi Join Video Consultation Room button maujood tha. Wajah markup me thi — buttons condition ke bahar likhe the:

PEHLE  <?php if (!empty($next_appointment)): ?>
         … name / date / time set karo …
       <?php endif; ?>

       <div class="…">                    <-- condition ke BAAHAR
         <button>Join Video Consultation Room</button>
         <button>Reschedule</button>
       </div>

Modals/markup PHP ke bahar hone se button har state me render hota tha. Data hi nahi tha, to click karne par patient khali Telehealth tab par land karta tha — jo user ko "redirection toota hua" lagta hai.

2. Ab teen saaf states

A. Koi appointment nahi

B. Appointment + meeting link

C. Appointment, link nahi

StateConditionButtonsClick kahan jata hai
A — koi appointment nahi empty($next_appointment) Book An Appointment + "No consultation scheduled yet." Appointments → booking form (data-appt-subtab="book")
B — appointment + valid link $ha_join_url non-empty aur https:// se shuru Join Video Consultation Room + Reschedule Meeting URL naye tab me (rel="noopener noreferrer") — real Zoom/Jitsi link
C — appointment, link nahi $ha_join_url khali View Consultation Details + Reschedule Telemedicine tab (jahan details render hoti hain)

Why state C matters: meeting link kai baar appointment create hone ke baad generate hota hai. Us window me "Join" dikhana galat tha — patient khali room par chala jata. Ab wahan "View Consultation Details" milta hai, jo sach me kuch dikhata hai.

Safety: link sirf tab use hota hai jab https:// se start hota ho — kisi bhi javascript: ya relative URL se button nahi banega.
